 # What is SmartPantry?
https://github.com/Lesedii3/Smart_Pantry_Manager.git
Ever open the fridge, stare into the cold, empty abyss, and say: "There's  nothing to eat"—even though it's stuffed full of random stuff?

SmartPantry is your personal, AI-powered kitchen sidekick that turns your chaotic fridge into a delicous meal.
It tracks your food, warns you before your milk expires, and crafts delicous snack recipes out of whatever weird combination of ingredients you have
left.

# Features That Are In The Application: 

# The Expiry Radar:
A literal countdown timer on your food so nothing secretly decays into a final boss in the back corner.

# Alchemist Recipe Generator: 
Got half an avocado, two eggs, and a piece of string cheese? Input them, and our AI will spit out a recipe that actually tastes good instead of cursed.
# 1. Pantry Inventory Management

Add ingredients to a digital pantry.

View stored pantry items.

Update ingredient information.

Remove ingredients that are no longer available.

Organise pantry items for easier tracking.

# 2. Recipe Management

Store recipe information.

Associate recipes with their required ingredients.

Support recipe discovery based on pantry ingredients.

Help users make better use of available food.

# 3. Local Database Storage

Uses SQLite for local data management.

Stores pantry items and recipe information.

Supports database operations using Java.

Enables data persistence between application sessions.

# 4. User-Friendly Interface

Android interface developed using XML layouts.

Simple navigation between application screens.

Easy-to-understand input fields and buttons.

Designed to provide an accessible mobile experience.
